# NetLab 3.5 (2.21.0): ห้องจำลองอยู่ในหน้าฝึกปฏิบัติเท่านั้น และเอาเมนูฝึกทำข้อสอบออก

## สิ่งที่เปลี่ยน
- เมนูด้านข้าง แถบเมนูล่าง (มือถือ) และการ์ดในแดชบอร์ด ไม่มี "ห้องปฏิบัติการจำลอง" และ "ฝึกทำข้อสอบ" แล้ว แถบเมนูล่างเป็น หน้าแรก · บทเรียน · การสอบ (ผู้เยี่ยมชม: คำศัพท์) · ผลการเรียน · เมนู
- นักเรียนและผู้เยี่ยมชมที่เปิดลิงก์เดิม ระบบพาไปหน้าที่ใช้แทน:
  | ลิงก์เดิม | ไปที่ |
  |---|---|
  | `#/sim/<ห้อง>/<ภารกิจ>` | หน้าฝึกปฏิบัติของสัปดาห์ที่มีภารกิจนั้น |
  | `#/practice/uN` | เนื้อหาบทแรกของหน่วย N |
  | `#/sims`, `#/sim/<ห้อง>`, `#/practice` | บทเรียน 18 สัปดาห์ |
- ครูและผู้ดูแลยังเปิดห้องจำลองแบบเต็มและหน้าฝึกทำข้อสอบได้จากลิงก์โดยตรง (สำหรับเตรียมสอน) แต่ไม่มีในเมนู
- ภารกิจเพิ่มเติมของแต่ละสัปดาห์ (ไม่บังคับ) ที่เดิมเปิดได้จากเมนูห้องจำลองเท่านั้น ย้ายมาอยู่ในหน้าฝึกปฏิบัติหัวข้อ "กิจกรรมเพิ่มเติม" เปิดในห้องจำลองแบบฝังเหมือนกัน ไม่นับคะแนนฝึกปฏิบัติ สัปดาห์ 18 มีโครงงานปิดท้ายรายวิชา (t9) ซึ่งยังใช้ในแฟ้มผลงานทักษะ
- เหรียญ "ขยันฝึก" "คลังความรู้" และ "รอบด้าน" (มาจากโหมดฝึกทำข้อสอบ) เลิกใช้ แสดงเฉพาะคนที่เคยได้แล้ว เหรียญห้องจำลอง "ครบทุกภารกิจ" นับเฉพาะภารกิจในฝึกปฏิบัติ 18 สัปดาห์
- ภารกิจประจำสัปดาห์ใช้เฉพาะ: ตอบโจทย์ลงมือในฝึกปฏิบัติ ผ่านภารกิจห้องจำลองในฝึกปฏิบัติ ทำแบบทดสอบหลังเรียน และเข้ามาเรียน
- คำแนะนำส่วนตัวและแผนการเรียนชี้ไปที่บทเรียนหรือหน้าฝึกปฏิบัติแทน
- คลังข้อสอบยังใช้กับ "การสอบ" ที่ครูเปิด คะแนนและประวัติเดิมของโหมดฝึกไม่ถูกลบ
- แก้บั๊ก: เปลี่ยนหน้าระหว่างที่แอปกำลังโหลดข้อมูลผู้ใช้ จะไม่ถูกพาไปหน้าผิดอีก

ไม่มีการเปลี่ยนฐานข้อมูล

## การทดสอบที่รันจริง
- ชุดทดสอบเซิร์ฟเวอร์ทั้งหมด (`npm run test:api`), `npm run test:content`, `npm test` ผ่าน
- e2e: part21 ตรวจว่าไม่มีลิงก์ไป `#/sims` หรือ `#/practice` ในเมนู แถบล่าง แดชบอร์ด และหน้าแนะนำการใช้งาน (ผู้เยี่ยมชมและนักเรียน จอคอมและ 360px) ตรวจการพาไปหน้าแทนทุกแบบ ครูยังเปิดหน้าเดิมได้ และโครงงาน t9 เปิดในหน้าฝึกปฏิบัติสัปดาห์ 18 โดยไม่นับคะแนนรอบฝึก ส่วนอื่นของ e2e ปรับให้ทำภารกิจผ่านหน้าฝึกปฏิบัติ (หรือเป็นครูเมื่อทดสอบห้องจำลองแบบเต็ม)
