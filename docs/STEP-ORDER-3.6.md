# NetLab 3.6 (2.22.0): ล็อกลำดับขั้นในสัปดาห์ และเอาปุ่มคำสั่งด่วนออก

## ล็อกลำดับขั้นในสัปดาห์
- ขั้นฝึกปฏิบัติเปิดเมื่อทำ **แบบทดสอบก่อนเรียน** แล้ว **อ่านเนื้อหาหลักครบ** และ **ทำแบบฝึกหัดระหว่างเรียนถูกครบ**
- ขั้นหลังเรียนเปิดเมื่อทำทุกข้อข้างบน และ **ผ่านฝึกปฏิบัติ** (หรือใช้สิทธิ์ฝึกปฏิบัติครบทุกรอบแล้ว เพื่อไม่ให้นักเรียนติดค้าง)
- ใช้เฉพาะเงื่อนไขที่ห้องเรียนกำหนดไว้ในแท็บ "เส้นทางการเรียน"
- งานที่เริ่มไปแล้วไม่ถูกล็อกย้อนหลัง (ฝึกปฏิบัติที่เคยเริ่ม แบบทดสอบหลังเรียนที่เคยทำ) สัปดาห์ที่ผ่านแล้วเปิดทุกขั้น
- ล็อกที่เซิร์ฟเวอร์: เริ่มฝึกปฏิบัติ เปิดภารกิจในฝึกปฏิบัติ และส่งแบบทดสอบหลังเรียน ตอบ 409 `step_locked` พร้อมรายการที่ยังขาด
- หน้าเว็บ: ขั้น 3 และ 4 ในแถบขั้นตอนแสดงไอคอนล็อก หน้าฝึกปฏิบัติและหน้าหลังเรียนแสดงสิ่งที่ต้องทำก่อนพร้อมลิงก์ แทนปุ่มเริ่มและข้อสอบ
- ครูปิด/เปิดได้ที่ "ล็อกลำดับขั้นในสัปดาห์" (ค่าเริ่มต้นเปิด ทุกห้อง) บันทึกในประวัติกติกา ครูไม่ถูกล็อก

## เอาปุ่มคำสั่งด่วนออก
เทอร์มินัลในหน้าฝึกปฏิบัติ (Command Prompt จำลอง) และเทอร์มินัลในห้องจำลองแบบฝัง ไม่มีปุ่มคำสั่งด่วนแล้ว นักเรียนต้องพิมพ์คำสั่งเอง (คำสั่ง `help` ยังแสดงรายการคำสั่ง) หน้าห้องจำลองแบบเต็มสำหรับครูยังมีปุ่มเหมือนเดิม

ไม่มีการเปลี่ยนโครงสร้างฐานข้อมูล
