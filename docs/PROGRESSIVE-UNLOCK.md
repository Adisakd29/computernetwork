# ระบบเรียนตามลำดับ (Sequential Learning & Progressive Unlock), เวอร์ชัน 2.15.0

## 1. สิ่งที่ตรวจในระบบเดิมก่อนพัฒนา

- **บทเรียนไม่มีการล็อก:** ทุกสัปดาห์เปิดให้ทุกคนตั้งแต่แรก หน้า 18 สัปดาห์เป็นรายการธรรมดา
- **แบบทดสอบหลังเรียน:** ทำได้ครั้งเดียวและเห็นเฉลยทันที ครูกด "ให้สอบใหม่" ได้ ตาราง `quiz_attempts` เก็บ 1 แถวต่อคนต่อสัปดาห์
- **ความก้าวหน้ามีอยู่ครบบนเซิร์ฟเวอร์แล้ว** ผูกกับ `users.id` ทั้งบัญชีปกติและบัญชี Google (`auth_identities` ชี้ไปที่ผู้ใช้คนเดียวกัน):
  - `lesson_progress`: หัวข้อที่อ่าน และแบบฝึกหัดที่ตอบ
  - `quiz_attempts`: คะแนนก่อนและหลังเรียน
  - `sim_results`: คะแนน Guided Lab
  - `task_progress`: แล็บท้ายคาบ
- **Guest:** เก็บงานใน localStorage เท่านั้น และนำเข้าบัญชีได้เมื่อสมัคร

ระบบใหม่จึงไม่ต้องย้ายคะแนน ทุกเงื่อนไขอ่านจากตารางเดิม ส่วนที่เพิ่มคือกติกา สถานะที่ผ่านแล้ว การปลดล็อกโดยครู และประวัติการสอบ

## 2. การทำงาน

### เงื่อนไขผ่านสัปดาห์

ค่าเริ่มต้นอยู่ที่เดียวคือ `content/learning-path.js` ครูแก้ได้รายห้องที่แท็บ "เส้นทางการเรียน"

| เงื่อนไข | ตรวจจาก | ค่าเริ่มต้น |
|---|---|---|
| ทำแบบทดสอบก่อนเรียน | มีคะแนนก่อนเรียน (คะแนนเท่าไรก็ได้ ไม่ใช้ล็อก) | เปิด |
| อ่านเนื้อหาหลักครบทุกหัวข้อ | หัวข้อหลักทุกหัวข้อใน `lesson_progress` (หัวข้อเสริมไม่บังคับ) | เปิด |
| ทำแบบฝึกหัดระหว่างเรียนถูกครบ | แบบฝึกหัดของหัวข้อหลักตอบถูกทุกข้อ | เปิด |
| ผ่าน Guided Lab ของสัปดาห์ | ทุกภารกิจ Guided ใน `content/curriculum.js` ได้อย่างน้อย 70% | เปิด, 70% |
| แบบทดสอบหลังเรียน | คะแนนครั้งที่ดีที่สุดอย่างน้อย 70% | เปิด, 70% |
| สอบหลังเรียนได้ | 3 ครั้ง เว้นระยะ 10 นาที ใช้คะแนนดีที่สุด | |
| เห็นเฉลย | เมื่อผ่านเกณฑ์ หรือเมื่อใช้สิทธิ์ครบ | |

ช่วงค่าที่ครูตั้งได้:
- เกณฑ์ % ตั้งได้ 40–100
- จำนวนครั้ง 1–10
- เวลารอ 0–1440 นาที
- ตั้งวันเปิดบทเรียนรายสัปดาห์ได้

### การปลดล็อก

- **สัปดาห์ 1** เปิดเสมอ
- **สัปดาห์ N** เปิดเมื่อสัปดาห์ N−1 เป็น Completed หรือมีการปลดล็อกจากครู ระบบไม่เปิดข้ามสัปดาห์
- **วันเปิดบทเรียน:** ถ้าตั้งไว้และยังไม่ถึงวัน สัปดาห์นั้นจะรอวันเปิด ยกเว้นครูปลดล็อกให้
- **บันทึกครั้งเดียว:** เมื่อเงื่อนไขครบ ระบบบันทึก Completed ลง `week_completions` ทันทีพร้อมเกณฑ์ขณะนั้น สัปดาห์ถัดไปเปิดในคำขอเดียวกัน
- **ผ่านแล้วผ่านเลย:** การเพิ่มเกณฑ์ภายหลังไม่ทำให้สัปดาห์ที่ผ่านแล้วกลับไปล็อก และนักเรียนทบทวนสัปดาห์ที่ผ่านได้ตลอด
- **การปลดล็อกโดยครู:**
  - เปิดเฉพาะสัปดาห์ที่เลือก ไม่ลามไปสัปดาห์ถัดไป
  - ทำได้ทั้งรายคนและทั้งห้อง ต้องใส่เหตุผล
  - เพิกถอนได้ และไม่มีการลบประวัติ

### การบังคับสิทธิ์ที่เซิร์ฟเวอร์

ทุก API ที่เกี่ยวกับสัปดาห์ที่ล็อกตอบ `403 {error:'locked'}`:
- เปิดบทเรียน บันทึกการอ่าน และส่งแบบฝึกหัด
- ส่งแบบทดสอบ
- เริ่มแล็บ ส่งคำตอบ และขอคำใบ้
- ส่งคะแนนห้องจำลองของภารกิจที่ใช้เฉพาะสัปดาห์ที่ล็อก

ผลคือ:
- **นักเรียนแก้สถานะเองไม่ได้:** ไม่มี API ให้นักเรียนเขียนสถานะ สถานะคำนวณจากคะแนนที่เซิร์ฟเวอร์ตรวจเองทุกครั้ง
- **การแก้ URL เช่น `#/lesson/w10`:** หน้าเว็บแสดงกล่องอธิบาย "ต้องผ่านสัปดาห์ที่ 9 ก่อน จึงจะสามารถเรียนบทเรียนนี้ได้" และปุ่ม "ไปเรียนสัปดาห์ที่ X" โดยไม่ขอเนื้อหาจากเซิร์ฟเวอร์ ถ้าเรียก API ตรง เซิร์ฟเวอร์ก็ปฏิเสธ
- **ส่งแบบทดสอบซ้อนกันพร้อมกัน:** ใช้ advisory lock จึงไม่ได้สิทธิ์สอบเกิน
- **ข้ามอุปกรณ์:** สถานะอยู่บนเซิร์ฟเวอร์ ผูกกับ User ID เข้าจากอุปกรณ์ไหนหรือเข้าด้วย Google ก็เห็นตรงกัน

### หน้าเว็บนักเรียน

- **สถานะ 4 แบบ** แต่ละแบบมีไอคอนและข้อความกำกับ ไม่ใช้สีอย่างเดียว:
  - ล็อก (แม่กุญแจ)
  - พร้อมเรียน (วงกลม)
  - กำลังเรียน (วงกลมครึ่ง)
  - ผ่านแล้ว (เครื่องหมายถูก)
- **หน้า "บทเรียน 18 สัปดาห์" เป็น Learning Path:**
  - มือถือ: แนวตั้งมีเส้นเชื่อม
  - แท็บเล็ต: 2 คอลัมน์
  - จอกว้าง: 3 คอลัมน์
  - สัปดาห์ที่ล็อกยังโฟกัสได้ ให้โปรแกรมอ่านหน้าจออ่านเหตุผลได้
- **แดชบอร์ด "เรียนต่อจากจุดล่าสุด"** แสดง:
  - สัปดาห์ปัจจุบัน
  - จำนวนที่ผ่านและที่เหลือ
  - คะแนนหลังเรียนเทียบเกณฑ์
  - สถานะ Guided Lab (ภารกิจในห้องจำลอง)
  - เงื่อนไขที่ยังขาด พร้อมลิงก์ไปทำ
  - สัปดาห์ถัดไปที่จะปลดล็อก
- **เมื่อปลดล็อกใหม่:** การ์ดมี animation สั้น ๆ และข้อความแจ้งเล็ก ๆ ที่หายเอง (`role="status"`) ถ้าผู้ใช้ตั้งลดการเคลื่อนไหว (`prefers-reduced-motion`) จะไม่มี animation
- **สอบหลังเรียนซ้ำ:** แสดงครั้งที่ สิทธิ์ที่เหลือ คะแนนดีที่สุด และเวลารอแบบนับถอยหลัง ถ้ายังไม่ถึงเวลาเห็นเฉลย จะแสดงข้อความแทนเฉลย
- **Guest** เห็นแถบ "โหมดผู้เยี่ยมชม: อ่านบทเรียนได้ทุกสัปดาห์ แต่ความก้าวหน้าจะไม่ถูกบันทึกและไม่มีการปลดล็อก เข้าสู่ระบบเพื่อเรียนตามลำดับ"

### หน้าครู (แท็บ "เส้นทางการเรียน")

- **สรุปห้อง:** เปิดหรือปิดการเรียนตามลำดับ เกณฑ์ และสัปดาห์ที่มีนักเรียนติดมากที่สุด
- **ตารางนักเรียน:**
  - จำนวนสัปดาห์ที่ผ่าน และสัปดาห์ที่ติดอยู่
  - เงื่อนไขที่ยังขาด
  - สถานะ 18 สัปดาห์ (ตัวอักษร ผ/ก/พ/ล พร้อมสี)
  - การเปิดพิเศษ
- **รายละเอียดรายคน:**
  - เงื่อนไขทุกข้อ
  - ประวัติการสอบหลังเรียนทุกครั้ง
  - ภารกิจที่ยังไม่ผ่าน
  - ปุ่มปลดล็อกรายคนและเพิกถอน
- **ฟอร์มกติกา:**
  - เรียนตามลำดับ
  - เกณฑ์หลังเรียน และเกณฑ์ Guided Lab
  - จำนวนครั้งที่สอบได้ และเวลารอ
  - เวลาที่เห็นเฉลย
  - เงื่อนไขที่บังคับ
  - วันเปิดบทเรียนรายสัปดาห์
- **ปลดล็อกทั้งห้อง** และ **ประวัติการปลดล็อกและการเปลี่ยนกติกา** (ใคร เมื่อไร เหตุผล)

## 5. ข้อจำกัดที่ทราบ

- **Guest อ่านบทเรียนได้ทุกสัปดาห์** เพราะไม่มีบัญชีให้ผูกสถานะ และไม่มีอะไรถูกบันทึก ถ้าต้องการบังคับลำดับต้องเข้าสู่ระบบ
- **โหมด "ฝึกทำข้อสอบ" (คลังข้อสอบ) และห้องจำลองที่ไม่ได้ผูกกับสัปดาห์ไม่ถูกล็อก** เป็นการฝึกเสริมที่ไม่มีผลต่อการผ่านสัปดาห์
- **ภารกิจห้องจำลองที่ใช้ในหลายสัปดาห์** ส่งคะแนนได้เมื่อสัปดาห์ใดสัปดาห์หนึ่งในนั้นเปิดอยู่
- **ปุ่ม "ดาวน์โหลดบทเรียนทั้ง 18 สัปดาห์" (ออฟไลน์)** ดาวน์โหลดเฉพาะสัปดาห์ที่เปิดแล้ว
- **ข้อความแจ้งปลดล็อก** แสดงบนอุปกรณ์ที่เคยเห็นเส้นทางการเรียนมาก่อน อุปกรณ์ใหม่จะเห็นสถานะใหม่โดยไม่มีข้อความแจ้ง
- **การปลดล็อกโดยครูขณะนักเรียนเปิดหน้าเว็บอยู่** อาจใช้เวลาถึง 20 วินาทีกว่าจะแสดง หรือแสดงทันทีเมื่อเปิดสัปดาห์นั้นหรือโหลดหน้าใหม่
