| wifi wf6 | 7 | Independent | ปานกลาง | Guest network: แยก SSID, WPA2/WPA3, Client isolation, ปิด WPS, เปลี่ยนรหัส admin |

**แบบจำลองของแล็บ Wi-Fi** (หน้าจอบอกว่าเป็น "ค่าประมาณ")
- สูตร: RSSI = กำลังส่ง + 3 dBi − PL(1 m: 40 dB ที่ 2.4 GHz, 47 dB ที่ 5 GHz) − 30·log10(d) − ค่าลดทอนของผนัง
- ค่าลดทอนต่อผนัง: ผนังเบา 4, กระจก 3, อิฐ 8, คอนกรีต 12, ลิฟต์/โลหะ 25 dB
- เกณฑ์ Co-channel interference: AP ที่อยู่ช่องทับกันได้ยินกันที่ −82 dBm ขึ้นไป
- ช่อง 2.4 GHz: 1–13 ช่องที่ห่างกันไม่ถึง 5 ถือว่าทับกัน
- ช่อง 5 GHz: แสดงช่อง DFS และการรวมช่อง 40/80 MHz

## 6. งานลงมือทำในแล็บท้ายคาบ

**การเพิ่มข้อ**
- ข้อใหม่ต่อท้ายข้อเดิม ข้อเดิมอยู่ตำแหน่งเดิม คีย์คำตอบที่บันทึกไว้ (`w1-0` ...) จึงยังหมายถึงข้อเดิม คะแนนที่นักเรียนได้แล้วไม่เปลี่ยน
- คะแนนเต็มของแล็บสัปดาห์ที่เพิ่มข้อจะสูงขึ้น ข้อละ 10 คะแนน นักเรียนที่ทำแล็บเสร็จไปแล้วจะเห็นข้อใหม่ค้างอยู่ ครูควรแจ้งนักเรียน
- ข้อใหม่ขึ้นต้นด้วย "ลงมือ:" หรือ "ลงมือตั้งค่า:"

**ประเภทงาน**
- อ่านค่าจากผลคำสั่งที่พิมพ์จริงใน Command Prompt จำลองของเครื่อง LAB-PC07
- กรอกหน้าตั้งค่า ระบบตรวจทุกช่องที่เซิร์ฟเวอร์

**สัปดาห์ที่เพิ่ม Command Prompt จำลองให้:** w1, w2, w3, w4, w10, w14, w15, w16, w18

**คำสั่งใหม่ใน Command Prompt จำลอง**
- net share <ชื่อ> (ดูสิทธิ์แชร์), net use (ดู/Map/ลบไดรฟ์)
- icacls, route print, netsh advfirewall show allprofiles [state]
- คำสั่งเปลี่ยนการตั้งค่าตอบตามจริงว่าต้องใช้สิทธิ์ Administrator
- netsh wlan ตอบว่าเครื่องตั้งโต๊ะนี้ไม่มีการ์ด Wi-Fi

**แก้ค่า TTL ใน ping ให้ตรงกับ tracert** (ค้างจาก Phase 1)
- ping 8.8.8.8 ได้ TTL 124: ค่าเริ่ม 128 ผ่าน Router 4 ตัว
- ping www.netlab.test ได้ TTL 59: ค่าเริ่ม 64 ผ่าน Router 5 ตัว
- Round-trip time ตรงกับ hop สุดท้ายของ tracert

## 10. ข้อจำกัดที่ทราบ (แจ้งตามจริง)

**แล็บ Wi-Fi**
- ไม่จำลองการสะท้อนและการเลี้ยวเบนของคลื่น สัญญาณหลังผนังหลายชั้นจึงต่ำกว่าของจริง
- ไม่มีย่าน 6 GHz
- จำนวน AP ที่ wf4 อนุญาตคำนวณจากวิธีวางแบบ Greedy จึงเป็นขอบบน ไม่ใช่ค่าน้อยที่สุดจริง
- ยังไม่ได้ทดสอบการลากและแตะบนจอโทรศัพท์จริง

**ห้องจำลองอื่น**
- Topology: ไม่จำลองความยาวสาย t18 ตรวจสาย 300 m จากอาคารที่สายเชื่อมอยู่ และหน้าจอบอกนักเรียนตรง ๆ ว่าห้องจำลองนี้ไม่คำนวณความยาวสาย
- Terminal: รหัสผ่านเก็บเพียงว่า "ตั้งแล้วหรือยัง" ไม่มี UAC และไม่จำลองตัวเลือก net user บางตัว เช่น /expires

**แล็บท้ายคาบ:** Command Prompt จำลองเป็นเครื่องเดียวกันทุกสัปดาห์ (LAB-PC07) ผลคำสั่งคงที่ จึงตรวจได้ว่านักเรียนอ่านผลถูกหรือไม่ แต่ไม่ได้ตรวจว่าพิมพ์คำสั่งเองจริง

**ภาพ**
- ภาพเดิมขนาดกว้างอ่านยากบนจอ 360px โดยไม่กดขยาย
- ภาพใหม่ตรวจด้วยภาพหน้าจอจากเบราว์เซอร์ทดสอบ ยังไม่ได้ตรวจบนมือถือจริงและด้วยโปรแกรมอ่านหน้าจอ

**สัดส่วนปฏิบัติ:** ยังไม่ถึง 70% ตามหัวข้อ 7
