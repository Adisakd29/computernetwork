# NetLab 3.3 (2.19.0): Embedded Virtual Lab ในหน้าฝึกปฏิบัติ

## สิ่งที่เปลี่ยน
- ภารกิจห้องจำลองในหน้าฝึกปฏิบัติ (`#/lesson/wN/lab`) มีปุ่ม **เปิดห้องจำลอง** กดแล้วห้องจำลองของภารกิจนั้นเปิดใต้การ์ดในหน้าเดียวกัน ไม่เปลี่ยนไปหน้ารวมภารกิจ
- ระหว่างเปิด workspace การ์ดอื่นถูกซ่อนชั่วคราว (focus mode) มีปุ่ม **กลับไปยังรายการฝึกปฏิบัติ** และบนจอเล็กมีปุ่ม **ขยายพื้นที่** (เต็มจอ กด Esc หรือปุ่มย้อนกลับเพื่อย่อ)
- หัว workspace แสดงส่วนของงาน ชื่อภารกิจ สถานะในรอบนี้ และ **เวลาที่เหลือจากตัวจับเวลาเดียวของฝึกปฏิบัติ** (ไม่สร้างเวลาใหม่ ไม่หยุดเมื่อปิดหรือสลับกิจกรรม) หมดเวลาระหว่างเปิดอยู่ ระบบปิด workspace และแสดงผลตามกฎเดิม
- ส่งงานในห้องจำลองแล้ว ผลถูกบันทึกเข้ารอบฝึกปฏิบัติ การ์ดและความคืบหน้าของส่วนนั้นอัปเดตทันทีโดยไม่ต้องรีโหลด (ผ่านเมื่อได้อย่างน้อย 70% ตามคะแนนจริง)
- ปิด workspace แล้วงานไม่หาย: คะแนนอยู่ที่เซิร์ฟเวอร์ งานที่ทำค้างอยู่ในร่างของห้องจำลอง (ร่างแยกตามภารกิจ ไม่ทับงานในหน้าห้องจำลองหลัก)

## Embedded Mode ของห้องจำลอง (ทั้ง 10 ห้อง)
`window.NL_SIMS[id].mount(root, ctx)` รับ `ctx.embedded = true` พร้อมภารกิจเดียว (`ctx.missions` 1 ข้อ, `ctx.initial`):
- เปิดภารกิจนั้นทันที ไม่มีรายการภารกิจ ไม่มีโหมดอิสระ/เครื่องมืออิสระ ไม่มีลิงก์ไปหน้ารวม และเปลี่ยนไปภารกิจอื่นไม่ได้
- เครื่องมือเดิมครบ: วางอุปกรณ์ ลากวาง ต่อสาย ตั้งค่า IP Ping คำแนะนำทีละขั้น ตรวจภารกิจ คะแนน บันทึกร่าง Undo/Redo โจทย์สุ่ม
- `destroy()` ล้างทุกอย่างที่เพิ่มนอก root
- เปิดจากเมนู **ห้องปฏิบัติการจำลอง** (`#/sims`, `#/sim/<id>`) ยังเป็น Standalone Mode เหมือนเดิม (รายการภารกิจและโหมดอิสระ)

## Backend
`GET /api/practical/:wid/mission/:sim/:mission` ตรวจว่าสัปดาห์เปิดให้นักเรียนคนนี้ (403 ถ้ายังล็อก) และภารกิจอยู่ในฝึกปฏิบัติของสัปดาห์นั้น (404 `not_in_week`) แล้วส่งเฉพาะภารกิจนั้น คะแนนดีที่สุด และผลในรอบที่กำลังทำ การส่งงานยังใช้ `POST /api/sims/:sim/submit` ซึ่งตรวจที่เซิร์ฟเวอร์ คะแนนไม่ซ้ำ: 1 แถวต่อภารกิจใน `sim_results` และ 1 แถวต่อภารกิจต่อรอบใน `practical_items` (เก็บคะแนนดีที่สุด) ไม่มีการเปลี่ยนโครงสร้างฐานข้อมูลในเวอร์ชันนี้

## กฎการเปิด
| สถานะ | เปิดได้ไหม | นับคะแนน |
|---|---|---|
| นักเรียน ยังไม่กดเริ่ม | ปุ่มบอก "กดเริ่มฝึกปฏิบัติก่อน" (ไม่เริ่มเวลาให้เอง) | - |
| นักเรียน กำลังทำรอบ | ได้ | นับเข้ารอบนี้ |
| นักเรียน ส่งงานแล้ว/หมดเวลา | ได้ (โหมดทบทวน) | ไม่นับในรอบที่จบแล้ว |
| ครู | ได้ (ดูตัวอย่าง ไม่จับเวลา) | ไม่นับเป็นคะแนนฝึกปฏิบัติ |
| ผู้เยี่ยมชม | ได้ (ฝึก) | ไม่บันทึก |

## การทดสอบที่รันจริง
- `tests/practical.test.js` เพิ่มการทดสอบ endpoint (ภารกิจเดียว ภารกิจสัปดาห์อื่น 404 สัปดาห์ที่ล็อก 403)
- `tests/e2e/part21.py` (ใหม่) 14 กรณีตามที่กำหนด บน 1280x800, 768x1024 (สัมผัส) และ 360x740 (สัมผัส): topology t1 ทำด้วยการคลิกจริงทั้งหมด (วางอุปกรณ์ ต่อสาย ตั้ง IP Ping Undo/Redo) x15 ทำจริงทั้ง 3 ขนาดจอ subnet s1, switching sw1, crimp c1 ทำและส่งบนเดสก์ท็อป
- ห้องจำลองทุกภารกิจ (100 ภารกิจ) ตรวจใน embedded mode ที่ 360px ระหว่างพัฒนา และ 66 ภารกิจของ 18 สัปดาห์ตรวจผ่านหน้าฝึกปฏิบัติจริง
- `tests/syntax-check.js` (ใหม่ อยู่ใน `npm run test:content`) ตรวจว่าทุกสคริปต์หน้าเว็บ parse ได้
- ยังไม่ได้ทดสอบอัตโนมัติ: การโต้ตอบจริงในห้องจำลอง ipv6, packets, netops, wifi และ terminal ภายใน workspace (เปิดและตรวจหน้าตาแล้ว), หมดเวลาระหว่างเปิด workspace ใน e2e (ทดสอบด้วยสคริปต์ระหว่างพัฒนา)
