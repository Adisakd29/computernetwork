### 2.1 ข้อผิดพลาดที่พบและแก้แล้ว

**แล็บและเทอร์มินัลจำลอง**
- **w1 แล็บข้อ 2 (จับคู่องค์ประกอบ 5 อย่าง):** แล็บใช้ "สถานีงาน/อุปกรณ์เครือข่าย" ขัดกับบทเรียนที่สอนผู้ส่ง ผู้รับ ข้อความ สื่อ โปรโตคอล แก้ให้ตรงบทเรียน
- **w1 แล็บข้อ 1:** คำอธิบายเฉลยไม่ตรงกับตัวเลือก ("ไม่เกี่ยวกับพลังงาน") แก้แล้ว
- **w4 แล็บ:** "10BASE2 ไกลสุดราว 180–185 เมตร" แก้เป็น 185 เมตรตามมาตรฐานและตามบทเรียน
- **w5 แล็บ:** ความยาวสายที่คลายเกลียว "1.2–1.5 ซม." เกินข้อกำหนด 13 มม. ที่บทเรียนสอน แก้เป็น 1.2–1.3 ซม.
- **w2 แล็บ:** คำใบ้ "LC = Little Connector" แก้เป็นชื่อเต็ม Lucent Connector
- **คำสั่ง `net view` ในเทอร์มินัลจำลอง:**
  - เดิมแสดงชื่อ Workgroup ซึ่ง Windows จริงไม่แสดง
  - เพิ่มคำสั่ง `net config workstation` (บรรทัด Workstation domain) แล้วแก้โจทย์ w8 ให้ใช้คำสั่งนี้
- **คำอธิบายผล ping เครื่องพิมพ์ (แล็บห้อง 10):**
  - เดิมบอกว่า "Request timed out = เครื่องปิด"
  - ที่ถูกคือในวงเดียวกัน เครื่องปิดจะขึ้น Destination host unreachable ส่วน timed out คือไม่ตอบ ICMP เช่นไฟร์วอลล์บล็อก
- **ชื่อโดเมนในเทอร์มินัลจำลอง:** เดิมใช้ `.local` ขัดกับบทเรียนสัปดาห์ 10 ที่เตือนเรื่อง mDNS เปลี่ยนเป็น `.internal`

**บทเรียน**
- **Full-duplex "คนละคู่สาย"** (สัปดาห์ 3, เนื้อหาเสริมสัปดาห์ 4 และคำบรรยายสื่อ): ถูกเฉพาะ 10/100 Mbps แก้ให้ระบุว่า 1000BASE-T ใช้ทั้ง 4 คู่ทั้งสองทิศ
- **คำศัพท์ Intranet (สัปดาห์ 10):** ตัวอย่าง `.local` แก้เป็น `.internal`
- **ตาราง Wi-Fi 7 (สัปดาห์ 6):** "23 Gbps ต่อย่าน" แก้ให้ระบุว่าได้เฉพาะช่อง 320 MHz ในย่าน 6 GHz
- **แล็บห้อง 6 (ตำแหน่งขาที่ 1 ของหัว RJ-45):** เพิ่มเงื่อนไขการถือหัว "ปลายหัวชี้ออกจากตัว"

**คลังข้อสอบ: คำสั่งที่ถูกต้องแต่ระบบเดิมตัดผิด**
- **u6-031:** ตอนนี้รับ `/del` และรับ path ของโฟลเดอร์ด้วย
- **u10-030:** ตอนนี้รับ `/del`
- **u8-013:** ตอนนี้รับ `netstat -a -n -o` แบบแยกตัวเลือก
- **u6-030:** ตอนนี้รับ `/p:yes`
- **u8-024:** ตอนนี้รับ `tracepath`
- **u6-021 (จับคู่สิทธิ์ Share/NTFS):** มี 2 แถวที่ตอบสลับกันก็ถูกได้ (Change กับ Modify ให้สิทธิ์เท่ากัน) ออกแบบแถวใหม่ให้มีคำตอบเดียว

**คลังข้อสอบ: ข้อความที่อาจทำให้เข้าใจผิด (ไม่มีข้อใดเฉลยผิด)**
- u2-017, u4-013, u4-015, u5-027, u1-048, u2-050, u6-007

**ที่ตรวจแล้วแต่ยังไม่แก้ (ไม่มีผลกับเฉลย)**
- tracert ในเทอร์มินัลจำลองไปยังปลายทางที่ไม่รู้จัก แสดงแค่ 1 บรรทัดแล้วจบ
- ค่า TTL ใน ping ไม่สัมพันธ์กับจำนวน hop ของ tracert

ทั้งสองเรื่องจะแก้ตอนสร้างเทอร์มินัลใหม่ใน Phase 3

## 4. สิ่งที่ตรวจไม่ได้ในรอบนี้

- **ทดสอบเว็บจริงด้วยเบราว์เซอร์:** เครื่องทดสอบเข้าเว็บ railway ผ่านเบราว์เซอร์ไม่ได้ (proxy ปฏิเสธ) ตรวจได้เฉพาะ API สาธารณะผ่าน WebFetch การทดสอบหน้าเว็บทั้งหมดทำกับเซิร์ฟเวอร์ในเครื่องทดสอบที่ใช้โค้ดชุดเดียวกัน
- **มือถือและแท็บเล็ตจริง:** ไม่ได้ทดสอบ
- **ภาพในสื่อ Interactive:** ผู้ตรวจอ่านข้อความ เฉลย และคำอธิบายของภาพทุกภาพ แต่ไม่ได้ตรวจความถูกต้องของภาพวาดทีละเส้น เช่นสีสายหรือตำแหน่งพอร์ต จะตรวจละเอียดใน Phase 4
- **Linux VM บูตจริง:** ไฟล์ kernel ดาวน์โหลดในเครื่องทดสอบไม่ได้

## 5. Curriculum Gap Analysis

ลำดับยังเป็น 21910-2013 คอลัมน์ "จะเติมที่" คือสัปดาห์ทางการที่ใกล้ที่สุด

- **บท** = มีในบทเรียน
- **แล็บจริง** = มีห้องจำลองที่ตรวจจากสถานะเครือข่าย
