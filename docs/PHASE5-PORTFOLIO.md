## 2. การประเมินทักษะ: หลักฐานมาจากไหน

ระดับทักษะยังคิดด้วยเกณฑ์เดิมของ 2.8 (`server/skills.js`) คือ งานลงมือทำ 70% และข้อสอบ 30% Phase นี้เพิ่มแหล่งหลักฐานดังนี้

| หลักฐาน | นับอย่างไร |
|---|---|
| ภารกิจห้องจำลอง | คะแนนดีที่สุดที่เซิร์ฟเวอร์ตรวจ แสดงชื่อภารกิจ ห้องจำลอง คะแนน และวันที่ |
| แล็บท้ายคาบและภารกิจท้าทาย | สัดส่วนข้อที่ตอบถูก เพิ่มสัปดาห์ w1–w4, w10, w15 ซึ่งมีงานลงมือทำตั้งแต่ Phase 4 |
| ครูบันทึกจากการปฏิบัติจริง (ใหม่) | ระดับ 1 = 40%, 2 = 70%, 3 = 90% (นับเป็นงานที่ผ่านเต็ม), 4 = 100% (นับเท่างานระดับยาก) |
| ข้อสอบ (ฝึกและสอบจริง) | คำตอบล่าสุดของแต่ละข้อ |

**ระดับ:** เริ่มต้น → กำลังพัฒนา → ทำได้ดี → เชี่ยวชาญ ใช้เกณฑ์ตัวเลขเดิม และแต่ละทักษะมีคำอธิบายพฤติกรรมที่สังเกตได้ 4 ระดับ ใน `content/rubrics.js`

**ตัวอย่างคำอธิบายระดับ:** Subnetting ระดับ "ทำได้ดี" คือ "แบ่ง Subnet ตามจำนวนเครื่องที่ต้องการได้ถูกต้อง และนำไปตั้งค่าในเครือข่ายจำลองได้"

**Skill Assessment รายสัปดาห์:** ขั้น "สรุปผล" ของแต่ละสัปดาห์แสดงระดับของทักษะที่สัปดาห์นั้นวัด ซึ่งมีมาตั้งแต่ Phase 2 และตอนนี้นับหลักฐานใหม่ทั้งหมดด้วย

## 3. โครงงานปิดท้าย (Capstone, สัปดาห์ 18)

**คะแนนมี 3 ส่วน แยกจากกัน**

| ส่วน | ผู้ตรวจ | คะแนน |
|---|---|---|
| ภารกิจ t9 ออกแบบเครือข่ายวิทยาลัย | ระบบตรวจจากเครือข่ายที่สร้าง (VLSM, Gateway, Wi-Fi, Firewall, การทดสอบ, แก้เหตุขัดข้อง) | 30 (เดิม) |
| รายงานเหตุผลการออกแบบ | ครู ใช้ Rubric เดิมในแท็บ "ตรวจงานโครงงาน" | 10 (เดิม) |
| การนำเสนอและป้องกันโครงงาน (ใหม่) | ครู ระหว่างนักเรียนสาธิตและตอบคำถาม | 5 เกณฑ์ × 4 ระดับ = 20 |

**เกณฑ์การนำเสนอและป้องกันโครงงาน:**
1. อธิบายการออกแบบและแผน IP
2. สาธิตการทำงานและการทดสอบ
3. แก้ปัญหาเฉพาะหน้าที่ครูกำหนด
4. มาตรการความปลอดภัย
5. การสื่อสารและเอกสาร

**การใช้ Rubric**
- ทุกเกณฑ์มีคำอธิบายครบ 4 ระดับ นักเรียนเห็นก่อนนำเสนอ
- ครูให้คะแนนบางเกณฑ์ก่อนแล้วค่อยเติมภายหลังได้

**คะแนน t9 เดิมไม่เปลี่ยน** ไม่ได้แก้เกณฑ์ของ t9 คะแนนที่นักเรียนได้แล้วจึงมีความหมายเท่าเดิม

## 4. วิธีใช้

**นักเรียน**
- เปิดเมนู "แฟ้มผลงานทักษะ" หรือปุ่มท้ายแผง "ทักษะของฉัน" ในหน้าความก้าวหน้า
- อ่านว่าตัวเองอยู่ระดับใด หลักฐานคืออะไร และขั้นต่อไปต้องทำอะไร
- เขียนสะท้อนคิด แล้วกด "พิมพ์ / บันทึกเป็น PDF" เพื่อส่งเป็นแฟ้มผลงาน

**ครู (หน้าครู → ห้องเรียน → แท็บ "แฟ้มผลงานทักษะ")**
- ตารางทั้งห้องแสดงระดับ 10 ทักษะ (1–4), จำนวนหลักฐานที่ครูบันทึก, จำนวนข้อความสะท้อนคิด และคะแนนโครงงาน
- กด "เปิดแฟ้ม" แล้วทำงานในแฟ้มของนักเรียนได้ดังนี้
  - บันทึกหลักฐานจากการปฏิบัติจริงในแต่ละทักษะ
  - เขียนความเห็น
  - ให้คะแนนการนำเสนอโครงงาน
  - พิมพ์แฟ้ม
- เปิดหรือปิด "บังคับฝึกปฏิบัติก่อนสอบหลังเรียน" ได้ที่แท็บ "ตั้งค่าห้อง"

**สิทธิ์การเข้าถึง**
- ครูเห็นและแก้ไขได้เฉพาะนักเรียนในห้องของตัวเอง ผู้ดูแลระบบ (admin) เห็นได้ทุกห้อง
- นักเรียนเห็นเฉพาะแฟ้มของตัวเอง และแก้ได้เฉพาะข้อความสะท้อนคิด
- ลบบัญชีนักเรียนแล้ว ข้อมูล Portfolio ของคนนั้นถูกลบด้วย

## 6. ข้อจำกัดที่ทราบ (แจ้งตามจริง)

**หลักฐานจากครู**
- หลักฐานที่ครูบันทึกมีน้ำหนักมาก บันทึกระดับ 3 หนึ่งครั้งและระดับ 4 หนึ่งครั้งก็ทำให้ทักษะนั้นถึงระดับ "เชี่ยวชาญ" ได้โดยไม่มีงานในระบบ ความน่าเชื่อถือจึงขึ้นกับดุลยพินิจของครู
- ระบบเก็บว่าใครบันทึกและเมื่อใด และนักเรียนเห็นทุกรายการ แต่ยังไม่มีประวัติการแก้ไข แก้รายการไม่ได้ ต้องลบแล้วบันทึกใหม่

**ระดับทักษะ:** แล็บท้ายคาบนับสัดส่วนข้อที่ตอบถูกทั้งแล็บ รวมข้อเลือกตอบด้วย ซึ่งเป็นวิธีเดิมของ 2.8

**แฟ้มผลงาน**
- ใช้ปุ่มพิมพ์ของเบราว์เซอร์สร้าง PDF รูปแบบจึงต่างกันเล็กน้อยตามเบราว์เซอร์
- ยังไม่มีลิงก์แชร์ให้บุคคลภายนอกดู ซึ่งเป็นการตั้งใจ เพื่อป้องกันข้อมูลส่วนบุคคล
- แฟ้มฝั่งครูยาวมาก (ทุกทักษะมีฟอร์มบันทึก) บนจอเล็กต้องเลื่อนนาน

**เงื่อนไขก่อนสอบหลังเรียน:** ตรวจเฉพาะภารกิจ Guided Lab ไม่ได้ตรวจแล็บท้ายคาบหรือ Independent Lab

**สัดส่วนปฏิบัติ:** ยังประมาณ 56% เท่ากับ Phase 4 เพราะ Phase นี้เน้นระบบประเมิน ไม่ได้เพิ่มกิจกรรม

**การทดสอบ**
- ทดสอบ Migration กับสำเนาข้อมูลที่สร้างจากโค้ดเวอร์ชันก่อน ยังไม่ได้ทดสอบกับฐานข้อมูลจริงบน Railway
- ยังไม่ได้ทดสอบบนมือถือจริงและด้วยโปรแกรมอ่านหน้าจอ
