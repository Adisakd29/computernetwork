# ภาพถ่ายอุปกรณ์จริง (เวอร์ชัน 2.16.0)

## 1. สิ่งที่เปลี่ยน

**ภาพถ่ายในบทเรียน**
- ภาพถ่ายจริง 74 ภาพ อยู่ใน 46 จุดของบทเรียน ครอบคลุมหน่วยที่ 1–9
- แต่ละภาพมี:
  - หมายเลขชี้ส่วนประกอบบนภาพ พร้อมคำอธิบายตามหมายเลขใต้ภาพ
  - คำบรรยาย (caption)
  - ข้อความสำหรับโปรแกรมอ่านหน้าจอ (alt)
  - เครดิตผู้ถ่าย
- กดดูภาพขนาดใหญ่ได้
- นักเรียนเปิดได้ทั้งบนมือถือและคอมพิวเตอร์ ธีมสว่างและมืด

**ภาพวาดที่ถูกแทนด้วยภาพถ่าย** (เก็บโค้ดภาพวาดไว้ ไม่ได้ลบ)
- `connectors`: หัวต่อ 6 แบบ ใช้ในสัปดาห์ 2 และ 5
- `device-ports`: พอร์ตของการ์ดแลน สวิตช์ เราเตอร์ และ SFP ในสัปดาห์ 2
- `crimp-tools`: คีมย้ำหัว หัว RJ-45 และ LAN Tester ในสัปดาห์ 5
- `rack-layout`: ตู้ Rack ในสัปดาห์ 13 ส่วนแถบเส้นทางสายยังเป็นภาพวาด เพราะเป็นแผนผัง

**ภาพวาดที่เก็บไว้คู่กับภาพถ่าย**
- เก็บไว้เพราะสอนสิ่งที่ภาพถ่ายแสดงไม่ได้:
  - ลำดับสีและหมายเลขขา T568A/T568B
  - ภาพตัดขวางสาย UTP/STP
  - ทางเดินแสงใน Single-mode และ Multi-mode
  - วิธีจับหัว RJ-45 ให้ขา 1 อยู่ซ้าย
  - ผังขา DB-9
  - ตัวอย่างที่ผิดในแต่ละขั้นของการเข้าหัว
- ภาพในห้องจำลองการเข้าหัว (crimp) ยังเป็นภาพวาด เพราะเปลี่ยนตามสิ่งที่นักเรียนทำ

**สัปดาห์ที่ไม่มีภาพถ่าย**
- สัปดาห์ 11–12 (หน่วยที่ 7) และ 17–18 (หน่วยที่ 10) สอนการติดตั้งและตั้งค่าระบบปฏิบัติการ และการจัดการบัญชีผู้ใช้ ซึ่งเป็นงานซอฟต์แวร์
- ในเนื้อหาไม่มีอุปกรณ์จริงที่ต้องใช้ภาพประกอบ จึงไม่ได้ใส่ภาพตกแต่ง
- หน่วยที่ 7 มีภาพในสัปดาห์ 10 แล้ว

## 2. ที่มาของภาพและสัญญาอนุญาต

- **Wikimedia Commons 71 ภาพ**
  - ภาพบน Commons ทุกภาพใช้สัญญาอนุญาตเสรี แต่ต้องระบุชื่อผู้ถ่ายและสัญญาอนุญาต
  - ใต้ทุกภาพมีลิงก์ไปยังหน้าไฟล์บน Commons ซึ่งแสดงชื่อผู้ถ่ายและสัญญาอนุญาตครบ
  - หน้า "ที่มาของภาพถ่าย" (`#/credits`) รวมภาพทั้งหมดไว้ที่เดียว
- **Pexels 3 ภาพ** ใช้ Pexels License (ใช้ฟรี ไม่บังคับระบุชื่อ แต่ระบบยังแสดงลิงก์ที่มา)
- **ยังไม่ได้ตรวจ:** ชื่อผู้ถ่ายและชื่อสัญญาอนุญาตของภาพจาก Commons ยังไม่ได้ดึงมาแสดงตรง ๆ เพราะเครื่องที่ใช้พัฒนาเข้า Commons ไม่ได้ ระบบจึงแสดงว่า "ดูชื่อผู้ถ่ายและสัญญาอนุญาตที่หน้าไฟล์" ไปก่อน
- **การเติมข้อมูลเครดิต:** ทำครั้งเดียวบนเครื่องที่ต่ออินเทอร์เน็ตปกติ
  ```
  node scripts/photo-credits.js            # ดึงชื่อผู้ถ่าย สัญญาอนุญาต และลิงก์สัญญาอนุญาต เขียนลง content/photo-credits.json
  node tests/photos-check.js --strict      # ต้องผ่านโดยไม่มีภาพที่ยังขาดเครดิต
  ```
  - จากนั้นนำ `content/photo-credits.json` ขึ้นระบบพร้อมโค้ด
  - ควรทำก่อนเผยแพร่ให้คนนอกห้องเรียน เพราะสัญญาอนุญาตบางแบบ (CC BY-SA 2.0/3.0) กำหนดให้แสดงชื่อผู้ถ่ายและชื่อสัญญาอนุญาตโดยตรง

**การแก้ไขภาพ**
- ภาพถูกย่อขนาด และบางภาพถูกครอป
- บางภาพเบลอป้ายทรัพย์สิน ชื่ออุปกรณ์ หรือข้อมูลเครื่อง
- ทุกภาพบันทึกสิ่งที่แก้ไว้ในช่อง `changes` และแสดงในเครดิต
- ตัวเลขชี้ส่วนประกอบเป็นข้อความ HTML ที่วางทับ ไม่ได้วาดลงในไฟล์ภาพ

## 3. การตรวจความถูกต้อง

- **ผู้ตรวจอิสระ:** ผู้ตรวจ 3 ชุดที่ไม่ได้เลือกภาพ ตรวจภาพทั้ง 74 ภาพเทียบกับชื่อภาพ ตำแหน่งตัวเลข คำอธิบาย และคำบรรยายในบทเรียน
- **สิ่งที่พบและแก้แล้ว:**
  - ตัวเลขวางผิดตำแหน่ง 34 ภาพ แก้ทั้งหมด และตรวจด้วยตาบนภาพทีละภาพ
  - BNC บิดล็อกหนึ่งในสี่รอบ (ประมาณ 90 องศา) ไม่ใช่ครึ่งรอบ
  - แกนกลางของสายโคแอกเชียลในภาพเป็นลวดตีเกลียว ไม่ใช่ทองแดงเส้นเดียว
  - FTTH ไม่ต้องใช้ ADSL Splitter แต่ในโครงข่ายยังมี Optical Splitter จึงแก้คำว่า "ไม่มี Splitter"
  - UPS ในภาพเป็นแบบตั้งโต๊ะ จึงระบุว่าในตู้ Rack ใช้ UPS แบบติดตู้
  - ประตูตู้ Rack ป้องกันได้เมื่อล็อกกุญแจแล้ว
  - แก้คำอธิบายภาพที่ไม่ตรงกับภาพ 6 จุด
- **ภาพที่เพิ่ม:** รางปลั๊กไฟสำหรับตู้ Rack (PDU) ในสัปดาห์ 13 เพราะเนื้อหาระบุ PDU เป็นส่วนประกอบของตู้แต่ยังไม่มีภาพ

**อุปกรณ์ที่ยังหาภาพถ่ายจริงที่เหมาะสมไม่ได้** (ยังเป็นข้อความหรือภาพวาดเดิม)
- สาย Console แบบ Rollover (RJ-45 ถึง DB-9)
- คีมปอกสายแบบหมุน
- Repeater ของ Ethernet
- รางเดินสายติดผนัง
- หัว RJ-45 Cat6 แบบมี Load bar

ครูถ่ายภาพอุปกรณ์ในห้องแล็บเองแล้วเพิ่มได้ตามข้อ 4

## 4. เพิ่มหรือเปลี่ยนภาพ

```
python3 scripts/photo-import.py <id> <ไฟล์ภาพ> --commons "File:ชื่อไฟล์.jpg"
```

1. คำสั่งนี้สร้าง `public/photos/<id>.jpg` (ด้านยาว 1600 px) และ `<id>-800.jpg`, ลบข้อมูล EXIF/GPS และพิมพ์รายการตัวอย่างให้คัดลอก
2. วางรายการลงใน `content/photos.d/<ชุด>.js` แล้วแก้ช่อง `title`, `alt`, `labels` (x, y เป็นเปอร์เซ็นต์ของภาพ) และ `credit`
   - ภาพที่ครูถ่ายเองใช้ `credit: { source: 'teacher', author: 'ชื่อครู' }`
3. วางภาพในบทเรียนผ่าน `content/lessons/visuals.d/p-*.js` ได้สามรูปแบบ:
   - `{ type:'photo', name:'<id>', caption }` ภาพเดียว
   - `{ type:'photos', names:['a','b'], caption }` แกลเลอรี 2–4 ภาพ
   - `{ type:'photo', name:'<ชื่อบล็อก>', photos:[...], layout:'grid', caption }`
4. ตรวจด้วย `node tests/photos-check.js` และ `node tests/lessons-check.js`

## 5. การทำงานออฟไลน์และความเร็ว

- **ขนาดภาพ:** มือถือโหลดภาพขนาด 800 px และโหลดเมื่อเลื่อนถึง (lazy) เท่านั้น
- **แคช:** ไฟล์ภาพมีรหัสเนื้อหาใน URL จึงแคชได้ยาว (1 ปี) เมื่อเปลี่ยนภาพ URL จะเปลี่ยนตาม
- **ออฟไลน์:**
  - Service Worker เก็บภาพที่เคยเปิดไว้ให้อ่านออฟไลน์
  - ปุ่ม "ดาวน์โหลดบทเรียนทั้ง 18 สัปดาห์" ดาวน์โหลดภาพขนาดเล็กไปด้วย
  - ภาพไม่อยู่ในชุดไฟล์ที่ติดตั้งตอนแรก (precache)
