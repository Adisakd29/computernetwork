# Rewritten bank questions (2.6)

Questions whose content was substantially rewritten in 2.6 (new question, options or key) got a NEW id. The 2.5 version stays in the unit file under the old id with `retired: true` and `replacedBy`, so:

- exam attempts made before 2.6 still review the question the student actually answered (same text, same key);
- retired questions are never drawn for practice or new exams, and do not count in bank statistics;
- "review mistakes" and guest review lists map an old id to its replacement.

Two items (u8-013, u8-024) only accept more valid command forms; they keep their ids.
