### w7: Wi-Fi security
- WEP (1997, RC4 with 40/104-bit key and 24-bit IV), WPA (2003, TKIP), WPA2 (2004, AES-CCMP), WPA3 (2018, SAE, PMF mandatory, forward secrecy). Correct.
- 4-way handshake offline dictionary attack on WPA2-PSK versus SAE. Correct.
- With TKIP, 802.11n and newer drop to legacy rates (54 Mbps). Correct.
- WPS PIN is checked in halves: 10^4 + 10^3 = 11,000 tries, because the last digit is a checksum. A recovered PIN reveals the PSK. Push-button versus PIN modes. Correct.
- Hidden SSID: removed from Beacons but still sent in Probe Request and Association Request. Clients probing for hidden networks leak the SSID. Correct.
- MAC filtering: MAC headers are unencrypted and spoofable, and conflicts with random/private MAC addresses. Correct.
- SSID up to 32 bytes. Passphrase 8 to 63 characters. Non-overlapping channels 1/6/11. Personal versus Enterprise (802.1X/RADIUS). WPA2/WPA3 transition mode. Guest network and client isolation. All correct.
- Ad-Hoc (IBSS), Infrastructure (BSS), Multiple APs (ESS) with roaming requiring the same SSID and security. Correct.
