## Checked and found correct (focus topics)

**Routing / gateway / troubleshooting (w13, w14)**
- Default Gateway = router IP used to reach other networks (w13 quiz #2, s4 table, w14 s2). Correct.
- Ping order 127.0.0.1 -> own IP -> gateway -> external IP (8.8.8.8) -> domain name, and the rule "the fault is between the first failing step and the last passing step" (w14 s2 steps and p, quiz #3, check). Correct. The caveats are also correct: a gateway may not answer ping, and pinging your own IP does not test the cable.
- Ping output strings are realistic for Windows 10/11: `Reply from x: bytes=32 time=1ms TTL=64`, `Request timed out.`, `Reply from <own IP>: Destination host unreachable.` (counted as Received, so 0% loss can appear), `Ping request could not find host ...`, `Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)`. Windows default is 4 echoes of 32 bytes; `-t`, `-n` are correct.
- tracert: TTL starts at 1, 3 probes per hop, 30 hops max by default, `-d` skips name lookup; `* * *` at one hop but later hops answer = router does not reply, not a break; `* * *` to the end = no path after the last hop that replied. The sample output (`<1 ms`, `dns.google [8.8.8.8]`, `Trace complete.`) is realistic.
- ipconfig /all lines (Physical Address, DHCP Enabled, `IPv4 Address ...(Preferred)`, Subnet Mask, Default Gateway, DHCP Server, DNS Servers) and APIPA output (`Autoconfiguration IPv4 Address ... 169.254.x.x(Preferred)`, mask 255.255.0.0, empty gateway) are realistic. APIPA usable range 169.254.1.0-169.254.254.255 is correct (RFC 3927). `(Duplicate)` for an IP conflict and `Media disconnected` are correct.
- netstat -an columns and states: LISTENING on 0.0.0.0, ESTABLISHED, TIME_WAIT, CLOSE_WAIT, and UDP `*:*` with no state. `-o` shows the PID. Correct.
- nslookup: Server/Address header, `Non-authoritative answer`, `UnKnown` when the server's reverse name is missing, `DNS request timed out.` Correct.
- /24 = 254 hosts, 192.168.20.255 = broadcast. Permanent link 90 m + about 10 m of patch cords = 100 m channel. 1U = 1.75 in = 4.445 cm. All correct.
- w14 quiz #10: the logic for "only one host fails beyond the gateway" is sound. Device Manager meanings: yellow ! = problem/driver, down arrow = disabled, Roll Back Driver. Correct.

**Security (w15, w16)**
- Malware definitions are precise: a virus needs a host file and user execution, then infects other files; a worm is standalone and spreads by itself through vulnerabilities; a trojan disguises itself and does not self-replicate; spyware/keylogger; ransomware encrypts and demands payment (sometimes double extortion); a rootkit hides itself and other malware (including at boot); a backdoor bypasses normal authentication. Comparison table is correct.
- WannaCry: 2017, spread like a worm through SMB/445, patch released about 2 months earlier (MS17-010, March 2017; outbreak May 2017). Correct.
- Phishing/Smishing/Vishing, Social Engineering, Shoulder Surfing, DDoS/Botnet, CIA mapping. Correct.
- 3-2-1 = 3 copies (1 working + 2 backups), at least 2 different media, at least 1 off-site, plus an offline copy against ransomware and regular restore tests. Correct. Full/Incremental/Differential descriptions are correct.
- Windows Defender Firewall: profiles Domain (selected automatically when a DC is reachable), Private, Public (default for new networks). Defaults per profile are Inbound block / Outbound allow. Rule types Program/Port/Predefined/Custom. Wizard steps Rule Type -> Protocol and Ports -> Action -> Profile -> Name. Actions include "Allow the connection if it is secure". Block beats Allow (no rule order). Inbound for a server, Outbound + remote port for blocking outgoing traffic. Predefined rule "File and Printer Sharing (Echo Request - ICMPv4-In)". Paths: wf.msc and Windows 11 Settings -> Privacy & security -> Windows Security -> Firewall & network protection. All correct.
- Microsoft Defender features (Real-time, Quick/Full/Custom/Offline scan, Security intelligence updates, Protection history/Quarantine, Controlled folder access, Tamper Protection), BitLocker on Pro+ / Device encryption on some Home devices, Get-FileHash / certutil -hashfile ... SHA256 / sha256sum. Correct.

**Accounts and permissions (w17, w18)**
- `net user`, `net user name`, `net user name * /add`, `/active:no|yes`, `/delete`, `net localgroup`, `net localgroup Group`, `net localgroup Group /add`, `net localgroup Group user /add|/delete`, `whoami` (prints lower-case `computer\user`). Syntax correct. "Local Group Memberships *Users" output is correct.
- lusrmgr.msc is not available on Home editions. New users go into Users by default. "User must change password at next logon" is ticked by default and conflicts with "User cannot change password" / "Password never expires". The built-in Administrator and Guest accounts are disabled by default, and the built-in Administrator is not subject to UAC Admin Approval by default. Correct.
- Share vs NTFS: share permissions apply only over the network; NTFS applies always. Effective network access = the more restrictive of the two. Within each layer, permissions from groups add together (the w17 s4 p and w18 term say this) and an explicit Deny wins. Share levels Full Control/Change/Read; NTFS levels Full control/Modify/Read & execute/List folder contents/Read/Write. Effective Access tab path. Correct.
- Give access to -> Specific people: Read, Read/Write, Remove, and Owner (display only). Correct.
- Linux: r=4 w=2 x=1; 755/750/644/640/600 strings; x on a directory = enter it; owner -> group -> others check order; chmod, chown user:group, usermod -aG, usermod -L / passwd -l. Correct. Quiz #6 (-rw-r----- read by others = Permission denied) and #10 (drwxr-x--- = 750) answer keys verified.
