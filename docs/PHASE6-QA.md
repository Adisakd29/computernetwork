# NetLab 3.0 Phase 6: ทดสอบทั้งระบบและตรวจโดยผู้ตรวจอิสระ (เวอร์ชัน 2.14.0)

## 1. วิธีตรวจ

ผู้ตรวจอิสระ 5 ชุดไม่ได้เป็นผู้สร้างระบบ และทำงานแบบอ่านอย่างเดียวบนเซิร์ฟเวอร์และฐานข้อมูลของตัวเอง ทุกข้อที่รายงานต้องทำซ้ำให้เห็นได้จริง หลังจากนั้นผู้แก้ 3 ชุดและผู้ประสานงาน (ฝั่งเซิร์ฟเวอร์) แก้ตามไฟล์ที่แบ่งกันไว้ และทุกการแก้มีชุดทดสอบอัตโนมัติยืนยัน

| ผู้ตรวจ | ขอบเขต |
|---|---|
| leak | ช่องทางได้คำตอบหรือคะแนนโดยไม่ทำงานจริง ตรวจห้องจำลองครบทุกภารกิจ บทเรียน แล็บ คลังข้อสอบ การสอบ และ Portfolio |
| sec | สิทธิ์การเข้าถึง (IDOR) 43 เส้นทาง, Stored XSS 18 ช่อง, CSRF, การตรวจข้อมูลเข้า, Session, ความเป็นส่วนตัว, Security headers |
| acc | ความถูกต้องทางเทคนิคของเนื้อหาที่เพิ่มใน Phase 3–5 |
| ui | หน้าจอ 4 ขนาด ธีมสว่างและมืด, axe WCAG 2.1 AA, คีย์บอร์ด, สถานะว่างและสถานะผิดพลาด, การพิมพ์ |
| perf | ความเร็วบนเครื่องช้าและเน็ตช้า, Service worker และการใช้งานออฟไลน์, ขนาด API, การถดถอยของฟีเจอร์เดิม |

**ผลรวม**
- ไม่พบช่องโหว่ด้านสิทธิ์การเข้าถึง ทุกเส้นทางที่รับ id ปฏิเสธครูต่างห้อง นักเรียน และผู้เยี่ยมชมถูกต้อง
- ไม่พบ XSS ทุก payload แสดงเป็นข้อความธรรมดา
- ไม่พบข้อเท็จจริงผิดที่จะถูกนำไปสอน
- ฟีเจอร์เดิมไม่ถดถอย
- ที่พบคือช่องทางได้คะแนนหรือเฉลยโดยไม่ทำงานจริงหลายจุด และข้อบกพร่องระดับกลางถึงต่ำหลายข้อ

## 4. ความถูกต้องของเนื้อหา (acc)

ไม่พบข้อเท็จจริงผิดที่จะถูกนำไปสอน ข้อชวนเข้าใจผิดและถ้อยคำ 10 ข้อแก้ครบแล้ว

| ข้อ | การแก้ |
|---|---|
| m12 สิทธิ์ `(RX,W)` | อธิบาย CREATOR OWNER และบอกว่า W เขียนทับไฟล์เพื่อนได้ พร้อมบอกข้อจำกัดของห้องจำลอง |
| NetOps o1 DNS | บอกว่า DNS ใช้ UDP 53 เป็นหลัก ส่วนการตรวจด้วย TCP 53 ในห้องจำลองเป็นการทำให้ง่ายขึ้น |
| Log ใน NetOps | เปลี่ยนข้อความ DHCP และ Power เป็นรูปแบบที่มีจริง |
| Rubric สายสัญญาณ | Split pair ต้องใช้เครื่องทดสอบที่วัด crosstalk (NEXT) |
| wf5 | ช่อง 1 กับ 6 ไม่เหลื่อมกัน ช่อง 3 เหลื่อมกับทั้งสองช่อง |
| wf1 | สัญญาณ 802.11b กว้างราว 22 MHz จึงต้องห่างกัน 5 ช่อง |
| w13 VLSM | ช่วงที่เหลือต่อเนื่องกันแต่ไม่ใช่ Subnet เดียว (.116/30 + .120/29 + .128/25) ทั้งในเนื้อหาและภาพ |
| sw4 | `show interfaces trunk` แสดง Native VLAN ส่วนข้อความ CDP ขึ้นที่ console |
| เครื่อง LAB-PC07 | MAC และ GUID ใน `net config workstation` ตรงกับ getmac, `ipconfig /all` มี DNS suffix และวันที่ของ Lease, banner เป็น Windows 11 (10.0.22631) |

## 5. หน้าจอ ความเร็ว และการถดถอย (ui, perf)

**แก้แล้ว**
- **Portfolio ที่พิมพ์:** ข้อความสะท้อนคิดยาวแสดงครบ ไม่ถูกตัด และพิมพ์จากธีมมืดได้ตัวอักษรเข้มบนกระดาษขาว
- **เกณฑ์ "ผ่าน" ใช้ 70% ทุกที่:** สรุปบทเรียน, Portfolio, เงื่อนไขก่อนสอบ, หน้าห้องจำลอง และแท็บห้องจำลองของครู
- **หน้าครู:** ปุ่มเปิดแฟ้มเห็นได้โดยไม่ต้องเลื่อน และแท็บตัดบรรทัดเองเมื่อจอแคบ
- **แถบขั้นตอนบทเรียนบนมือถือ:** เลื่อนให้เห็นขั้นปัจจุบันเสมอ
- **axe WCAG AA:** แก้สีตัวอักษรตัดกับพื้นไม่พอ 3 จุด และกล่องที่เลื่อนดูได้ 2 จุดให้ใช้คีย์บอร์ดได้
- **Command Prompt ในแล็บบนมือถือ:**
  - ช่องพิมพ์ 16px สูง 44px และปุ่มลัดสูง 40px
  - มีปุ่มตัดบรรทัดและคำใบ้ให้เลื่อนดูด้านข้าง
  - แถบเวลาไม่บังจอเทอร์มินัล
- **NetOps บนมือถือ:** แผนผังแสดงขนาดจริงและเลื่อนดูด้านข้างได้ และอธิบายศัพท์ (poll interval, threshold, Top Talker, playbook)
- **สถานะผิดพลาดของ Portfolio:** ข้อความภาษาไทยพร้อมปุ่มลองใหม่
- **ชื่อเรียก:** ใช้ชุดเดียวกัน "แฟ้มผลงานทักษะ", "ฝึกตามขั้นตอน (Guided Lab)", "ฝึกเอง (Independent Lab)", "แก้ปัญหา (Troubleshooting Challenge)"
- **ไฟล์ภาพสอนโหลดเมื่อต้องใช้:** หน้าแรกโหลดข้อมูลครั้งแรกจาก 558 KB เหลือ 166 KB ภาพยังอยู่ใน Service worker จึงอ่านออฟไลน์ได้ตามเดิม
- **ข้อมูลผลห้องจำลองในหน้าบทเรียน:** ใช้ `/api/sims/done` ที่เล็กกว่าเดิมมาก แทน `/api/sims` (447 KB)
- **สคริปต์ทดสอบ:** หยุดเฉพาะเซิร์ฟเวอร์ของตัวเอง ไม่ฆ่า node process อื่นในเครื่อง

**ยังไม่ได้แก้ (ระดับต่ำ)**
- จุด AP บนแผนผัง Wi-Fi ที่จอ 390px มีขนาด 26×26px ใช้ปุ่มลูกศรหรือช่อง x/y แทนการลากได้
- หน้าแล็บมีหัวข้อ H1 ซ้ำ 2 อัน
- ลิงก์ใน `.gatebox` สูง 19px
- `/api/me` ยังส่งเฉลยหลังเรียนของทุกบทเรียนทุกครั้ง (54 KB)
- การ render บทเรียน w4 ใช้เวลาต่อเนื่องราว 1 วินาทีบนเครื่องช้า 4 เท่า

**การถดถอย:** ผู้ตรวจ perf ตรวจฟีเจอร์เดิมด้วยมือ ทั้ง Excel 3 แบบ, แท็บครู 11 แท็บ, ไฟล์สำรอง, โปรไฟล์, รูปประจำตัว, หน้าประวัติ และ Google login ทำงานครบทุกอย่าง

## 6. ข้อจำกัดที่ทราบ (แจ้งตามจริง)

**ห้องจำลองทำงานในเบราว์เซอร์** นักเรียนที่เปิดเครื่องมือนักพัฒนาอาจเห็นข้อมูลที่ใช้สร้างโจทย์ เช่น รายการเหตุการณ์ของ NetOps แต่ไม่เห็นออบเจ็กต์คำตอบแล้ว และปลอมคะแนนไม่ได้ เพราะเซิร์ฟเวอร์ตรวจใหม่ทุกครั้ง

**สคริปต์เตรียมโจทย์ Linux VM** ยังเรียกดูได้ เพราะเครื่องจำลองทำงานในเบราว์เซอร์ flag ของภารกิจ VM จึงเป็นการฝึก ไม่ควรใช้เป็นคะแนนสอบ

**CSP กับ Linux VM (v86)** ยังไม่ได้ทดสอบ เพราะไฟล์ v86 ไม่อยู่ในเครื่องทดสอบ ถ้า VM บูตไม่ได้บนระบบจริง ตั้ง `CSP=report-only` ชั่วคราวแล้วแจ้งกลับ

**e2e ทดสอบ CSP แบบ Report-Only** เพราะ Playwright ประเมิน predicate ในหน้าเว็บ ซึ่ง CSP แบบบังคับจะบล็อก part16 ตรวจว่าไม่มีการละเมิดนโยบายแม้แต่ครั้งเดียว และ `security.test.js` ตรวจว่าค่าเริ่มต้นเป็นแบบบังคับ

**การล็อกบัญชีในห้องเรียน** นักเรียนยังล็อกบัญชีเพื่อนได้ 15 นาที ด้วยการใส่รหัสผิด 8 ครั้งจาก IP เดียวกัน

**ยังไม่ได้ทดสอบ** บนมือถือจริง ด้วยโปรแกรมอ่านหน้าจอ และบนระบบจริงที่ Railway
