# Phase 2: หลักสูตร 18 สัปดาห์และ Mapping ข้อมูลเดิม (NetLab 3.0)

## 1. หลักการ

- **ลำดับสัปดาห์** คงตามแผนทางการ 21910-2013 ตามที่ครูเลือก หัวข้อจากโครงสร้าง 18 Strand ของคำสั่ง 3.0 (VLAN, NAT/PAT, IPv6, Cloud/SDN ฯลฯ) ถูกวางในสัปดาห์ทางการที่ใกล้ที่สุด แต่ละสัปดาห์ระบุ Strand ไว้
- **ทุกสัปดาห์มี 8 องค์ประกอบ** และจัดลงหน้าบทเรียน 6 ขั้นดังนี้

| ขั้นในหน้าบทเรียน | องค์ประกอบ |
|---|---|
| ก่อนเรียน | Pre-test |
| เนื้อหา | Interactive Learning Content และ Technical Diagrams |
| ฝึกปฏิบัติ | Guided Lab และ Independent Lab |
| ภารกิจท้าทาย | Troubleshooting Challenge และภารกิจจับเวลา (ห้องฝึกเดิม) |
| หลังเรียน | Post-test |
| สรุปผล | Skill Assessment |

- **ข้อมูลอยู่ไฟล์เดียว** คือ `content/curriculum.js` หน้าเว็บอ่านผ่าน `GET /api/curriculum`
  - ไฟล์นี้อ้างถึงกิจกรรมที่มีอยู่จริงเท่านั้น
  - สิ่งที่ยังไม่ได้สร้างอยู่ในช่อง `planned` และ**ไม่แสดงเป็นปุ่มให้นักเรียนกด**
- **Mapping ข้อมูลเดิม**
  - ไม่มีการเปลี่ยนคีย์บทเรียน แล็บ ข้อสอบ หรือภารกิจห้องจำลอง คะแนนเดิมทุกตารางใช้ต่อได้ทันที จึงไม่ต้องมี Database migration ในรอบนี้
  - ภารกิจห้องจำลองที่นักเรียนผ่านแล้วจะขึ้น "ผ่านแล้ว" ในสัปดาห์ที่อ้างถึงภารกิจนั้น
- **Skill Assessment** ใช้ระบบระดับทักษะ 10 ด้านเดิม (ลงมือทำ 70% ความรู้ 30%) แต่ละสัปดาห์ระบุทักษะที่วัด

## 2. สิ่งที่ใช้ได้ทันทีหลัง deploy รอบนี้

- **ขั้นฝึกปฏิบัติ:** มีกล่อง "แผนฝึกปฏิบัติของสัปดาห์นี้" แบ่งเป็น
  - **Guided Lab:** แล็บท้ายคาบ + ภารกิจที่มีคำใบ้
  - **Independent Lab**
  - แต่ละภารกิจแสดงระดับ เวลาโดยประมาณ และผลของนักเรียน (ผ่านแล้ว / ได้ x/y / ยังไม่ได้ทำ)
- **ขั้นภารกิจท้าทาย:** มี Troubleshooting Challenge ของสัปดาห์อยู่ก่อนภารกิจจับเวลา
- **ขั้นสรุปผล:** มี "ผลการฝึกปฏิบัติ" นับภารกิจที่ผ่านเต็มในแต่ละประเภท และแสดงเป้าหมายสมรรถนะของสัปดาห์
- **ภารกิจห้องจำลองทั้ง 51 ภารกิจ** ถูกจัดเข้าสัปดาห์ครบ (ตรวจด้วย `tests/curriculum-check.js`)

## 3. สัดส่วนปฏิบัติ : ทฤษฎี (ประมาณจากเวลา)

**วิธีคิด**

ภาคทฤษฎี:
- แบบทดสอบก่อนและหลังเรียน ครั้งละ 10 นาที
- เวลาอ่านตามที่บทเรียนกำหนด
- แบบฝึกในบทเรียน ข้อละ 1 นาที
- ข้อเลือกตอบหรือเรียงลำดับในแล็บท้ายคาบ

ภาคปฏิบัติ:
- ข้อตอบจากเทอร์มินัล ฟอร์มตั้งค่า และ Linux VM ในแล็บท้ายคาบ
- ภารกิจห้องจำลอง: ง่าย 10 / ปานกลาง 15 / ยาก 25 นาที

ภารกิจจับเวลาเดิม: นับครึ่งทฤษฎีครึ่งปฏิบัติ

## 4. แผนรายสัปดาห์ (8 องค์ประกอบ)

### สัปดาห์ 1: ความรู้เกี่ยวกับระบบเครือข่ายคอมพิวเตอร์

**ประเด็นหลัก:** พื้นฐานเครือข่าย องค์ประกอบ ประเภท และ Topology (Strand 1, 2)

**เมื่อจบสัปดาห์ นักเรียนทำได้:** ระบุองค์ประกอบการสื่อสารข้อมูลจากสถานการณ์จริง · ต่อ PC 2 เครื่องผ่าน Switch และทดสอบด้วย ping

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 5 + เสริม 2 · สื่อโต้ตอบ 4 · แบบฝึกระหว่างเรียน 5 ข้อ |
| Technical Diagrams | 7 ภาพ |
| Guided Lab | แล็บท้ายคาบ 15 นาที (8 ข้อ) · T8 โหมดฝึกทีละขั้น: จาก 2 เครื่องสู่ 2 วงเครือข่าย |
| Independent Lab | T1 PC 2 เครื่องคุยกันผ่าน Switch |
| Troubleshooting Challenge | X1 PC7 เข้าเว็บไม่ได้ แต่เพื่อนเข้าได้ · ภารกิจจับเวลา: ท้าทาย ส.1 พื้นฐานเครือข่ายและ Topology |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | ออกแบบเครือข่าย, Switching และ LAN (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

### สัปดาห์ 2: อุปกรณ์และสื่อนำสัญญาณ

**ประเด็นหลัก:** อุปกรณ์เครือข่าย สื่อนำสัญญาณ และหัวต่อ (Strand 2, 3)

**เมื่อจบสัปดาห์ นักเรียนทำได้:** เลือกอุปกรณ์และสื่อให้เหมาะกับงาน · อ่านผลเครื่องทดสอบสาย LAN

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 5 + เสริม 3 · สื่อโต้ตอบ 3 · แบบฝึกระหว่างเรียน 5 ข้อ |
| Technical Diagrams | 6 ภาพ |
| Guided Lab | แล็บท้ายคาบ 15 นาที (8 ข้อ) · T2 ห้องแล็บเล็ก: PC 4 เครื่อง + เครื่องพิมพ์ |
| Independent Lab | C7 อ่านไฟเครื่องทดสอบสาย LAN |
| Troubleshooting Challenge | C4 หาจุดเสียของสาย LAN · ภารกิจจับเวลา: ท้าทาย ส.2 อุปกรณ์และสื่อนำสัญญาณ |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | ออกแบบเครือข่าย, สายสัญญาณและการเข้าหัว (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

### สัปดาห์ 3: มาตรฐานและโปรโตคอลของระบบเครือข่าย

**ประเด็นหลัก:** มาตรฐาน OSI/TCP-IP โปรโตคอล และ IPv4 แบบ Classful (Strand 1, 6)

**เมื่อจบสัปดาห์ นักเรียนทำได้:** ระบุชั้น OSI ของอุปกรณ์และโปรโตคอล · บอก Class, Mask และช่วง IP ได้

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 6 + เสริม 2 · สื่อโต้ตอบ 6 · แบบฝึกระหว่างเรียน 6 ข้อ |
| Technical Diagrams | 9 ภาพ |
| Guided Lab | แล็บท้ายคาบ 15 นาที (9 ข้อ) · S1 Classful: หา Class, Mask และช่วง IP |
| Independent Lab | M3 ARP กับ TTL: ใครตอบ ping ของเรา |
| Troubleshooting Challenge | X9 สั่งพิมพ์ไม่ออกตั้งแต่มีเครื่องใหม่ · ภารกิจจับเวลา: ท้าทาย ส.3 OSI, TCP/IP และโปรโตคอล |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | ตั้งค่า IP, คำนวณ Subnet (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

**จะเพิ่มใน Phase ถัดไป:** (P3) แล็บ Encapsulation: ดูข้อมูลถูกห่อทีละชั้นจากแพ็กเก็ตจริงในเครือข่ายจำลอง

### สัปดาห์ 4: เครือข่าย LAN แบบใช้สาย: เทคโนโลยีและมาตรฐาน

**ประเด็นหลัก:** Ethernet, Switching, ตาราง MAC และ ARP (Strand 4, 5)

**เมื่อจบสัปดาห์ นักเรียนทำได้:** อธิบายการเรียนรู้ MAC ของ Switch จากผลจริง · แยก Collision domain ของ Hub กับ Switch

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 5 + เสริม 4 · สื่อโต้ตอบ 6 · แบบฝึกระหว่างเรียน 5 ข้อ |
| Technical Diagrams | 6 ภาพ |
| Guided Lab | แล็บท้ายคาบ 15 นาที (8 ข้อ) · T1 PC 2 เครื่องคุยกันผ่าน Switch |
| Independent Lab | M3 ARP กับ TTL: ใครตอบ ping ของเรา |
| Troubleshooting Challenge | (ยังไม่มี ดูแผนด้านล่าง) · ภารกิจจับเวลา: ท้าทาย ส.4-1 ข้อมูล สัญญาณ และการส่งข้อมูล · ท้าทาย ส.4-2 การตรวจจับและควบคุมข้อผิดพลาด |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | Switching และ LAN (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

**จะเพิ่มใน Phase ถัดไป:** (P3) แล็บตาราง MAC/ARP แบบเห็นการเรียนรู้ทีละเฟรม · (P3) แล็บ VLAN, Trunk 802.1Q และ STP พื้นฐานใน NetSim · (P4) เนื้อหาเสริม Managed Switch, VLAN, Trunk และ STP

### สัปดาห์ 5: เครือข่าย LAN แบบใช้สาย: การเข้าสาย UTP กับ RJ-45

**ประเด็นหลัก:** เข้าหัว UTP/RJ-45 และทดสอบสาย (Strand 3)

**เมื่อจบสัปดาห์ นักเรียนทำได้:** เข้าหัว T568A/B ตามขั้นตอนและตรวจคุณภาพ · หาจุดเสียของสายจากผลเครื่องทดสอบ

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 5 · สื่อโต้ตอบ 2 · แบบฝึกระหว่างเรียน 5 ข้อ |
| Technical Diagrams | 6 ภาพ |
| Guided Lab | แล็บท้ายคาบ 15 นาที (8 ข้อ) · C6 เข้าหัวตามขั้นตอนจริง + ตรวจคุณภาพ (QC) |
| Independent Lab | C1 สาย LAN แบบตรง (straight-through) มาตรฐาน T568B · C2 สาย LAN แบบตรง มาตรฐาน T568A · C3 สาย LAN แบบไขว้ (crossover) · C5 สายแพทช์ตามกฎห้องแล็บ |
| Troubleshooting Challenge | C4 หาจุดเสียของสาย LAN · C7 อ่านไฟเครื่องทดสอบสาย LAN · ภารกิจจับเวลา: ท้าทาย ส.5 LAN ใช้สาย, Ethernet และการเข้าหัว UTP |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | สายสัญญาณและการเข้าหัว (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

**เมื่อจบสัปดาห์ นักเรียนทำได้:** กำหนดสิทธิ์ตามหลัก Least Privilege · ออกแบบ ตั้งค่า ทดสอบ และแก้ปัญหาเครือข่ายวิทยาลัยแบบครบวงจร

| องค์ประกอบ | สิ่งที่ใช้ |
|---|---|
| Pre-test | 10 ข้อ (มีอยู่) |
| Interactive Learning Content | หัวข้อหลัก 6 · สื่อโต้ตอบ 2 · แบบฝึกระหว่างเรียน 5 ข้อ |
| Technical Diagrams | 4 ภาพ |
| Guided Lab | แล็บท้ายคาบ 25 นาที (5 ข้อ + Linux VM 6) |
| Independent Lab | T9 โครงงานปิดท้าย: ออกแบบเครือข่ายวิทยาลัย |
| Troubleshooting Challenge | (ยังไม่มี ดูแผนด้านล่าง) · ภารกิจจับเวลา: ท้าทาย ส.18 บัญชีผู้ใช้ กลุ่ม และสิทธิ์การใช้งาน |
| Post-test | 10 ข้อ ฉบับคู่ขนาน (มีอยู่) |
| Skill Assessment | ออกแบบเครือข่าย, Routing และ Gateway, คำนวณ Subnet, เครือข่ายไร้สาย, ความปลอดภัย (คิดจากหลักฐาน: ลงมือทำ 70% ข้อสอบ 30%) |

**จะเพิ่มใน Phase ถัดไป:** (P5) Skills Portfolio รวมหลักฐานงานจริงทุกสัปดาห์และ Rubric รายทักษะ


## 5. สิ่งที่ Phase 2 ยังไม่ได้ทำ (ตามจริง)

- **ภารกิจที่ใช้ซ้ำหลายสัปดาห์:** บางภารกิจถูกอ้างใน 2 สัปดาห์ เช่น t6 ใน w6/w7 และ m3 ใน w3/w4 เพราะยังไม่มีภารกิจเฉพาะ ทำครั้งเดียว คะแนนนับที่เดียว
- **สัปดาห์ที่ยังขาดบางองค์ประกอบ:**
  - ยังไม่มี Independent Lab: w6, w7, w17
  - ยังไม่มี Guided mission: w12, w17, w18 ซึ่งมีแล็บท้ายคาบเป็น Guided Lab อยู่แล้ว
  - ยังไม่มี Troubleshooting Challenge: w4, w18
  - รายการที่จะเติมระบุไว้ในตารางของแต่ละสัปดาห์
- **เกณฑ์ "เรียนจบสัปดาห์" ยังเหมือนเดิม** คือส่งแล็บท้ายคาบและทำแบบทดสอบหลังเรียน ภารกิจห้องจำลองยังไม่บังคับ เพื่อไม่ให้สถานะของนักเรียนที่เรียนจบไปแล้วเปลี่ยน
  - ถ้าครูต้องการบังคับ จะเพิ่มเป็นตัวเลือกต่อห้องเรียนในหน้าครูได้ใน Phase 5
- **ตัวเลขสัดส่วนเวลาเป็นค่าประมาณ** ไม่ใช่เวลาที่วัดจากการใช้งานจริง
